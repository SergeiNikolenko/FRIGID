These came from the 321-spectrum clean-panel run, before the connectivity rule. A candidate marked in pieces is one the mask now refuses: the decoder had finished a molecule and then padded it up to the target mass with fragments that share no bond with it.

Teacher-forced: at every position the prefix is the gold answer, so the ranking shown is what the model would have proposed had it written the molecule correctly up to that point. Probabilities come from the same sampling_logits call the sampler makes; verdicts come from the same mask the evaluation run builds, and a token is attributed to the first restriction that refuses it.
